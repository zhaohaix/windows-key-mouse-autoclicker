# 全键鼠自动连点

一个中文界面的 Windows 键盘、鼠标自动连点工具，内置白色点击测试窗口。支持编排动作、组合键、次数或无限循环、定时启动和全局快捷键。

## 功能

- 键盘：A–Z、0–9、空格、回车、方向键、F1–F12 等，以及 `Ctrl+A` 等组合键。
- 鼠标：左键、右键、中键；点击当前位置或指定屏幕坐标。
- 按顺序执行多个动作，分别设置间隔和重复次数。
- 指定循环轮数、无限循环、启动倒计时及定时启动。
- 默认 **F8 启动／暂停／继续，F9 紧急停止**，可修改。
- 内置点击测试器，显示点击次数、位置及键盘输入，支持清零。
- 保存配置，导入和导出 JSON。

## 使用

1. 从仓库的 Releases 下载 Windows EXE（有发布版本时），或按下方步骤从源码打包。
2. 双击 `全键鼠自动连点.exe`。
3. 添加动作，或选择已有动作修改后点击“更新选中”。
4. 设置间隔和循环轮数，按 F8 启动，默认有 3 秒切换到目标窗口。
5. 按 F8 暂停／继续，按 F9 停止。

想先测试效果：点击主界面右上角“打开测试窗口”，在白色区域按 F8。默认配置会发送 10 次空格。关闭测试窗口会停止连点并取消预约；点击“返回连点设置”可以调整动作。

“重复次数”是单个动作执行次数；“循环轮数”是整套动作执行轮数。间隔单位为秒，表示每次动作完成后的等待时间。鼠标坐标为空时点击当前位置。

配置保存在 `%APPDATA%\FullKeyClicker\config.json`。再次打开恢复设置，但不会自动执行任务或恢复预约。预约使用电脑本地时间，需要软件保持运行、电脑处于唤醒状态。

## 源码运行

适用于 Windows 10/11 64 位。代码使用 Python 标准库，GUI 使用 Tkinter，模拟输入使用 Windows SendInput。开发时使用 Python 3.14；其他 Python 版本尚未逐一验证。

```powershell
py autoclicker.py
```

独立测试器也可单独运行：

```powershell
py click_tester.py
```

## 打包 EXE

```powershell
py -m pip install -r requirements-build.txt
py -m PyInstaller --noconfirm --onefile --windowed --name 全键鼠自动连点 autoclicker.py
```

输出位于 `dist`。测试窗口已包含在 EXE 内，无需另装依赖。

## 验证

```powershell
py -m unittest -v test_autoclicker.py
py native_selftest.py
```

`native_selftest.py` 会打开内置测试窗口，逐个核对 65 个单键的原生按下／释放消息，并检查组合键、鼠标、循环、暂停、停止及定时等功能。测试需要前台焦点，必要时在 30 秒内切到“自动验收测试”窗口。验收期间请勿手动输入。测试使用临时配置，详细结果输出至本地 `测试结果.json`。

目前本机验收 79 项通过，自动回归测试 7 项通过；结果只代表本机测试窗口。尚无跨设备兼容性验证。已有程序占用的组合键可能被截获，部分游戏或管理员程序也可能不接受模拟输入。实际间隔受系统调度影响。

## 文件

| 文件 | 用途 |
| --- | --- |
| `autoclicker.py` | 主程序、动作执行及全局快捷键 |
| `click_tester.py` | 内置／独立白色测试器 |
| `test_autoclicker.py` | 自动回归测试 |
| `native_selftest.py` | 真实输入集成验收 |
| `使用说明.txt` | 详细使用说明 |

关闭主程序会停止任务。首次使用建议先设置少量次数，在测试器确认效果后再使用无限循环。
