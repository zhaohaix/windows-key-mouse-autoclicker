全键鼠自动连点 — Windows 10/11 64 位

打开 dist 文件夹中的“全键鼠自动连点.exe”即可使用，无需安装 Python。
本版本已内置点击测试器：点击主界面右上角“打开测试窗口”即可使用，无需另开 EXE。
测试器可显示鼠标点击和键盘次数，支持清零和返回设置。关闭测试窗口会停止连点并取消预约。

快速开始
1. 默认有一个空格动作。选择动作可编辑；点击“更新选中”保存修改。
2. 添加需要的键盘、鼠标或等待动作，通过上移/下移调整顺序。
3. 设置每个动作的间隔（秒）及重复次数，再设置整套动作循环轮数。
4. 点击启动或按 F8，默认留 3 秒时间切换到目标窗口。
5. F8 暂停/继续；F9 紧急停止并取消预约。快捷键可修改，修改后点击“应用快捷键”。

动作说明
- 支持 A-Z、0-9、空格、回车、方向键、F1-F12 及界面下拉列表中的键。
- 组合键输入 Ctrl+A、Ctrl+Shift+A 等。按键会按顺序按下、反向释放。
- 字母按键模拟物理键，字符大小写和实际文字取决于输入法及 Caps Lock。
- 鼠标支持左、右、中键；坐标留空则点击鼠标当前位置。
- 获取固定坐标：点击“3秒后取鼠标坐标”，将鼠标移到目标位置，随后添加或更新动作。
- “间隔”指每次按键/点击后的等待时间；“等待”动作仅等待指定时长。
- “重复次数”指单个动作重复次数；“循环轮数”指整套动作执行次数。
- 最小间隔 0.01 秒；实际速度受系统调度和目标程序影响。
- 当前启动和停止快捷键不能作为自动执行动作。

预约与配置
- 预约使用电脑本地时间，格式：年-月-日 时:分:秒；触发后仍执行启动倒计时。
- 预约期间请保持软件运行、电脑唤醒，并提前切到目标窗口。
- 暂停会冻结当前等待进度；紧急停止会终止当前任务，再次启动从头执行。
- 运行或预约期间修改动作、导入配置前，请先停止或取消预约。
- 关闭软件自动保存配置，但不保存运行状态及预约；再次打开不会自动执行。
- 配置位置：%APPDATA%\FullKeyClicker\config.json；也可手动导出和导入 JSON。

兼容性
- 输入发送到当前前台窗口，使用时请切换到需要操作的软件。
- 若目标软件以管理员权限运行，本软件也可能需要右键“以管理员身份运行”。
- 部分游戏或软件会阻止模拟输入，不保证兼容这些程序。
- 快捷键被其他程序占用时，界面会提示；更换快捷键并应用后再启动。

开发与构建
源代码：autoclicker.py（仅依赖 Python 标准库）
测试：py -m unittest -v test_autoclicker.py
安装打包工具：py -m pip install pyinstaller
打包：py -m PyInstaller --noconfirm --clean --onefile --windowed --name 全键鼠自动连点 autoclicker.py
